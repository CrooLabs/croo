# Playground

These are the games that ship with Croo's Playground, as plain HTML — open
any of them in a browser. They're written for Croo, and Croo is where
they're meant to live: drop a file into `var/games/` and it appears in
your Playground menu. Make them yours within Croo.

So if you've changed or deleted a game and want the original back, take
its file from [games/](games/) and save it into `var/games/` — it shows
up on the next open. Want to write your own? Start with the
[authoring guide](authoring-guide.md).
