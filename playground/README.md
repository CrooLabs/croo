# Playground

These are the games that ship with Croo's Playground, as plain HTML — open
any of them in a browser. They're written for Croo, and Croo is where
they're meant to live: drop a folder into `var/games/` and it appears in
your Playground menu. Make them yours within Croo.

Everything in this folder is under the MIT licence (see [LICENSE](LICENSE))
— unlike the rest of this repository, you're free to copy and modify it.

*The game folders and the guide to writing your own are added here from
each Croo release.*
