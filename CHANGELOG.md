# Croo Changelog

Release notes for activated Croo releases, newest first.

## v1.0.8 - 19 October 2026

<!-- release_id: croo-1008-R1 -->

- Cleaner Grok replies: task lists, queued messages and running-tool status no longer appear as part of the agent's reply.
- Follow your update: open your custodian's pane directly from Updates while the update continues.
- Fleet at a glance: a percentage ring and compact glyph counts show active agents, waiting agents and Power-Through, with labels on hover.
- Steadier updates: older installations no longer trip over a leftover Python environment. Early update failures now record a clearer reason.

## v1.0.7 - 19 October 2026

<!-- release_id: croo-1007-R1 -->

- Reorganised menus and more consistent action icons.
- New Minima fleet display with grouped activity and Power-Through status.
- More consistent Model and Effort controls, plus Gemini 4 Argon choices where available.
- Browse Tips by topic, search or device, and enlarge demonstrations full screen.
- Improved version reporting and browser cache handling.
- Keyboard shortcut labels matched to your browser’s platform.
- New-browser defaults: Usage 2×2, Monitor Rings and a seven-minute Power-Through window; existing preferences stay unchanged.
- Open project-relative file and folder references directly from agent replies.
- Improved Antigravity conversation identification and approval handling.

## v1.0.6 - 18 October 2026

<!-- release_id: croo-1006-R1 -->

- Paste screenshots directly into Notes and view them in pop-out sticky notes.
- Respond to Claude, Codex and AGY folder-trust prompts directly in Croo.
- Retry interrupted Nova setup without repeating the installation.
- Improved Power-Through handling of large Claude approval prompts.
- Consistent alignment in the Fields menu.
- Improved Tips loading.

## v1.0.5 - 17 October 2026

<!-- release_id: croo-1005-R1 -->

- Sticky notes: sticky-note windows open reliably.
- Engine changes: startup settings stay consistent with the selected engine.
- Workmap: title previews are easier to read.
- AGY messages: multiline messages remain together in the conversation.
- Claude model changes: no extra confirmation, and idle panes are recognized correctly even when the terminal has extra blank space.

## v1.0.4 - 15 October 2026

<!-- release_id: croo-1004-R1 -->

- Help & Tips: access keyboard shortcuts and illustrated tips from the Croo logo, with optional automatic tips during quiet moments.
- Live Workmap updates: changes appear automatically while the map is open, without interrupting your edits.
- Cleaner conversations: reduced leftover input echoes and idle footer clutter in Claude's Gamma view.
- Codex conveniences: Plugins added to More, plus F3 conversation search in the main Echo view.
- Quick agent popups: Cmd-click a bottom agent tab to open its popup.
- Optional sidebar summaries: local-AI summaries help you see what agents are doing at a glance.
- Clearer system monitoring: simplified Spark, Rings and Bars displays, with detailed information available on hover.
- More reliable Grok approvals: approval choices remain usable when another message is queued.

## v1.0.03 - 15 October 2026

<!-- release_id: croo-1003-R1 -->

- Set project-wide Git guidance for a shared branch or separate agent workspaces, with clearer setup instructions and branch suggestions.
- Follow branches, commits and file changes in a visual Git activity view, with recorded agent contributions and readable commit descriptions.
- Ask Nova to guide you through a Git example, and copy agent instructions directly from project settings.
- Open PDFs, images and supported media inside Croo, then close the viewer to return to your work. View and copy the file path without leaving the preview.
- Read larger pinned-draft previews, identify attachments by their paperclip, and use an improved message-box layout in narrow panels.
- See active, waiting and Power-through-enabled agents in the refreshed fleet summary. Sidebar file names are easier to read.
- Compact AGY conversations directly from Croo on supported engine versions.
- Get clearer confirmation when changing a Codex model or reasoning effort, with fixes for numbered question choices and approval buttons.
- Find relevant commands in refreshed engine-specific More menus, with improved Grok approval handling and cleaner conversation output.

## v0.9.78 - 11 October 2026

<!-- release_id: croo-978-R1 -->

- The agent header no longer falls back to an account default while a message is queued behind an Antigravity turn.
- A file an agent writes after the page opened appears in the sidebar search within a minute, or as soon as you click into the search box. The file list also loads much faster.
- Codex's "send input to terminal N?" approval is answered by Power Through and by the choice buttons.
- The chat view hides Claude's idle-compaction bookkeeping instead of showing it as a reply.
- Voice setup help says which part is missing.
- The project header's map and settings buttons sit flush right.
